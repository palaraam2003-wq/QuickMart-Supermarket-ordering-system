# RapidMart — Manual Test Cases & Acceptance Matrix

| Test ID | Role | Feature / Workflow | Action / Steps | Expected Result | Pass/Fail |
|---|---|---|---|---|---|
| TC-01 | Public | Registration | Navigate to `/register.html`, fill customer form, submit. | Account created, redirected to login with success message. | Pass |
| TC-02 | Public | Security Role Escalation | Attempt to register with role `MANAGER` via browser inspect or curl payload. | Payload role ignored; account created strictly with `CUSTOMER` role. | Pass |
| TC-03 | Customer | Address Management | Navigate to `/profile.html`, add new delivery address. | Address saved, listed under active addresses. | Pass |
| TC-04 | Customer | Cart & Checkout | Add products from `/catalogue.html`, proceed to `/checkout.html`, choose COD, select future date, submit. | Order created, stock deducted, cart cleared, redirected to confirmation. | Pass |
| TC-05 | Customer | Past Delivery Date | On `/checkout.html`, attempt to select today or a past delivery date. | Client and server validation error: "Delivery date must be strictly in the future." | Pass |
| TC-06 | Cashier | EFT Payment Verification | Login as Cashier (`cashier@rapidmart.local`), open `/cashier/dashboard.html`, enter tax and delivery charge for a pending EFT order, then verify payment. | Payment status becomes `PAID`, Order status becomes `CONFIRMED`, immutable Bill generated with the entered charges. | Pass |
| TC-07 | Cashier | COD Settlement Confirmation | Open COD Settlements tab, select pending driver cash collection, confirm receipt. | Cash settlement marked confirmed by cashier. | Pass |
| TC-08 | Inventory | Soft Deactivation | Login as an Inventory Officer, view the product list on `/inventory/products.html`, click Deactivate. | Product `active` state becomes `false`. Product disappears from public catalogue but remains in history. | Pass |
| TC-08A | Inventory Officer | Create Stock Request | Login as `inventory@rapidmart.local`, open `/inventory/stock-operations.html`, create a stock request for a product. | Request listed as `PENDING` in the Stock Request History; no Approve/Reject buttons are shown; stock is unchanged. A second request for the same product is refused (409). | |
| TC-08B | Manager | Approve / Reject Stock Request | Login as the manager, open *Stock Approval Requests* on `/manager/dashboard.html`. Approve one request, optionally lowering the quantity; reject another with a reason (Reject without a reason is blocked). | Approved/rejected rows leave the pending list; stock is unchanged; the decision and reason appear in the officer's history and in the audit log. | |
| TC-08C | Inventory Officer | Receive Approved Stock | As the officer, find the request under *Receive Approved Stock*, click Receive Stock and confirm. | Stock increases once by the received quantity; one `RECEIVED_STOCK` movement referencing `RESTOCK_REQ_<id>` appears; the request becomes `RECEIVED`. Pending and rejected requests never offer Receive Stock. | |
| TC-09 | Coordinator | Delivery Staff Assignment | Open `/delivery-coordinator/dashboard.html`, select unassigned order, assign active driver and slot. | Delivery status changes to `ASSIGNED`. Conflict prevention blocks assigning same driver to overlapping slot. | Pass |
| TC-09A | Coordinator | Delivery Staff Management | Add a delivery staff account, search for it, update the profile, inspect assignments, then deactivate it. | Driver is created with only `DELIVERY_STAFF`; filters and availability work; active assignments must be reassigned before deactivation. | Pass |
| TC-10 | Driver | Complete COD Delivery | Login as Driver (`driver1@rapidmart.local`), mark order `OUT_FOR_DELIVERY`, complete delivery & record exact cash. | Order status becomes `DELIVERED`, Payment status becomes `PAID`, loyalty points credited to customer. | Pass |
| TC-11 | Manager | Employee Management | Login as Demo Manager (`manager@rapidmart.local`), create new employee user with `CASHIER` role. | Employee created, logged in audit trail. | Pass |
| TC-12 | Manager | Self-Demotion Safeguard | Manager attempts to remove their own `MANAGER` role or deactivate own account. | Operation rejected with business exception: "Manager cannot demote or deactivate themselves." | Pass |
| TC-13 | Manager | Sales Report & CSV | Open `/manager/dashboard.html`, generate Sales Summary, click Export CSV. | CSV downloaded with proper headers and formula injection sanitization. | Pass |
| TC-14 | Loyalty Officer / Manager | Concurrent Loyalty Edit | Open the same tier or offer in two sessions, save different changes in both. | First save succeeds; stale second save receives HTTP 409 and reloads the current record without overwriting it. | Pass |
